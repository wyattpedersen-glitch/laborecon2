# Econ 151 · Midterm 2 study site

Single-page study site for UC Berkeley Econ 151 (Labor Economics), Midterm 2 (Thu Oct 29), covering lectures 6–8: employer market power, wage-setting (posting vs bargaining), and regulation (minimum wages, noncompetes, pay transparency).

Open `index.html` in a browser, or deploy the repo as a static site (e.g. Vercel with framework "Other" and no build command). Math renders via MathJax from a CDN, so an internet connection is needed. Checkboxes, drill streaks and the current tab persist in the browser.

Tabs: Plan (Mon–Thu schedule), Attack plans (steps, why, mnemonics), Drills (15 randomized generators with worked steps), L6 / L7 / L8 lecture pages, 12 Papers (go-to picks by research design, prompt bank), Designs, HW3 solved, Practice exams (official practice question plus a full exam), Flashcards, Cheat sheet.
